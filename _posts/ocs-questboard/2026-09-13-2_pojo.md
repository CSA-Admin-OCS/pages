# Questboard POJO Implementation

## What I Built

For my project, I created a `Questboard` POJO (Plain Old Java Object) to represent quests in my Questboard application.

The purpose of this class is to store information about each quest, including its title, description, difficulty, XP reward, status, and deadline. Instead of having different variables scattered throughout the application, the Questboard class groups all of this related information into one object.

This makes the application easier to organize and allows other parts of the Spring MVC application to work with quests as objects.

The main fields I included were:

- id -- uniquely identifies the quest
- title -- the name of the quest
- description -- explains what the quest is about
- difficulty -- represents how difficult the quest is
- xp -- stores the experience points earned
- status -- represents the current state of the quest
- deadline -- stores the quest deadline

## How I Built It

```java
package com.open.spring.mvc.questboard;

import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;

@Data
@NoArgsConstructor
@AllArgsConstructor

public class Questboard {
    private Long id;
    private String title;
    private String description;
    private String difficulty;
    private int xp;
    private String status;
    private String deadline;
}
```

I used Lombok in order to reduce the amount of repetitive code neccessary, all in all making the code much cleaner.

`@Data` generates Getters, Setters, toString(), equals(), hashCode(), etc. This allows us to shorten our variables from something like `public Long getId() { return id; }` to the much shorter and cleaner version that is seen in the code above, `private Long id;`.

`@NoArgsConstructor` creates a constructor without any parameters, mimicing `Questboard quest = new Questboard();`

`@AllArgsConstructor` creates a constructor with all paramters filled, mimicing `Questboard quest = new Questboard(1L, "Create a Plan", "Write a plan for Spring 1 Final", "HARD", 250, "OPEN", "2026-09-14");`

## Lombok Methods

The `@Data` annotation, as noted before, generates many methods for the Questboard Class.
- Getters - Getters allow for other classes to get the values of the private instance variables
- Setters - Setters allow for the change of private instance variables
- toString() - This method creates a string representation of the Questboard object
- equals() - This method determines whether two objects are equal based on field values
- hashCode() - This method generates a hash code based on the fields.

## Proof of Functionality

We can create a quick test in order to see whether or not our POJO works.

```java
package com.open.spring.mvc.questboard;

public class QuestboardTest {

    public static void main(String[] args) {

        // Create a Questboard object
        Questboard quest = new Questboard(
                1L,
                "Create a Plan",
                "Write a plan for Spring 1 Final",
                "HARD",
                250,
                "OPEN",
                "2026-09-14"
        );

        // Test get
        System.out.println("ID: " + quest.getId());
        System.out.println("Title: " + quest.getTitle());
        System.out.println("Description: " + quest.getDescription());
        System.out.println("Difficulty: " + quest.getDifficulty());
        System.out.println("XP: " + quest.getXp());
        System.out.println("Status: " + quest.getStatus());
        System.out.println("Deadline: " + quest.getDeadline());

        // Test a setter
        quest.setStatus("DONE");

        System.out.println("New Status: " + quest.getStatus());
    }
}
```
