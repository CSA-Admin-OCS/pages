# OCS-in-a-Kit Demo (1 minute)

## Setup before people arrive

- Logged in as Admin on an installed kit (Education shows the most).
- Demo screen: tab 1 is a lesson with the code runner, tab 2 is the admin dashboard.
- Capstone page open on the other screen.

## Script

| Time | Say | Show |
|---|---|---|
| 0:00 to 0:15 | "OCS built a full classroom platform, but it only worked for one school. We turned it into a kit, so any school or company can install its own copy. [One sentence on your mentor role.]" | Capstone page, top |
| 0:15 to 0:35 | "This is a school that installed the Education kit. Students write and run real code right in the browser, with lessons, grading, and a hall pass all built in." | Lesson tab, run a line of code |
| 0:35 to 0:50 | "The admin picks what the site has. There are 16 features, and I can switch any of them on or off, no reinstall." | Admin dashboard, toggle one feature |
| 0:50 to 1:00 | "The same code also ships as a Business kit with no classroom features. [Name] can walk you through how it's built." | Hand off to a teammate |

## If someone wants more

Show the Compare the Kits table on the capstone page.

## If something breaks

Switch to the capstone page and use the Example: A Teacher Sets Up a Classroom flowchart to tell the same story.

## Before tonight

Practice the feature toggle once so you know which feature switches cleanly.
